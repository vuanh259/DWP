# Simple Interest Calculator

A simple application designed to calculate the simple interest earned or owed based on principal, rate, and time.

## Formula Used

The calculator uses the standard simple interest formula:

$$A = P(1 + rt)$$

Where:
* **A** = Total Amount (Principal + Interest)
* **P** = Principal amount
* **r** = Annual interest rate (in decimal form, e.g., 5% = 0.05)
* **t** = Time period (in years)

Alternatively, to find just the Interest (I):
$$I = P \cdot r \cdot t$$
